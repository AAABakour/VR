# VR Modern Game UI Upgrade

## What was added

A new runtime-generated, game-style HUD was added through:

- `Assets/Scripts/UI/ModernSimulationGameUI.cs`

The UI auto-installs itself when `MainSimulationScene` starts. It does not require manual scene wiring, and it hides the old `MainUI` to avoid duplicate controls.

## Main UI areas

### Top command bar
- Project title and simulation cockpit identity.
- Live state chip: Running / Paused.
- FPS chip.
- Paint tank percentage.
- Fluid film status.
- Rope type and tension.
- HUD hide button.

### Left telemetry panel
- Paint tank meter.
- Particle count.
- Impact state.
- Surface film coverage / wetness / max thickness.
- Quick actions: Pause, Reset, Clear, Refill.

### Right control deck
A large interactive control deck with live sliders, toggles, dropdowns, and buttons.

Sections:

1. Scene Modes
   - Clean Spiral
   - Splashy Paint
   - Dense Flow
   - Double Hole
   - Metal Spread
   - Restart Motion

2. Paint Source
   - Paint amount
   - Flow rate
   - Hole diameter
   - Paint viscosity
   - Particles per unit flow
   - Random spread
   - Nozzle shape
   - Internal slosh
   - Paint color buttons

3. Particle Flight
   - Max particles
   - Gravity
   - Air drag
   - Turbulence
   - Wind strength
   - Cohesion
   - Separation
   - Air turbulence toggle
   - Visual droplets toggle

4. Real Fluid Film
   - Enable fluid film
   - Solve whole film
   - Solver interval
   - Substeps
   - Fluid viscosity
   - Pressure spread
   - Surface gravity
   - Adhesion
   - Surface tension
   - Wet friction

5. Canvas + Wet Visuals
   - Surface type
   - Paint opacity
   - Spray amount
   - Smear length
   - Edge irregularity
   - Thickness visibility
   - Normal strength
   - Directional smear
   - Wet shading
   - Dynamic normal map

6. Bucket Motion
   - Rope length
   - Start angle X
   - Start angle Z
   - Damping
   - Depth swing
   - Bucket wobble
   - Torsion
   - Depth swing enabled

7. Rope Rig
   - Rope type
   - Tautness
   - Max sag
   - Bend stiffness
   - Wave amplitude
   - Segments
   - Tension color

8. Output + Debug
   - Save image
   - Save report
   - Save all
   - Step film once

## Keyboard shortcuts

- `1` Clean Spiral
- `2` Splashy Paint
- `3` Dense Flow
- `4` Double Hole
- `5` Metal Spread
- `Space` Pause / Resume
- `R` Reset
- `F` Toggle Fluid Film
- `H` Hide / Show HUD

## Design direction

The UI was designed to make the project feel like an interactive simulation game rather than a raw Unity prototype:

- Dark glass-panel style.
- Neon/cyan/blue technical accent colors.
- Real-time control deck.
- Dashboard telemetry.
- Quick preset action bar.
- Runtime-generated rounded panels and controls.

## Notes

This UI is generated by code at runtime so it remains robust even if the scene hierarchy changes. If a custom hand-designed UI is later preferred, this script can become the logic controller behind prefab-based UI panels.
